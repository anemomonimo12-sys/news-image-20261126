# News Image — 26 November 2026

A newspaper front page summing up Thursday 26 November 2026's world
news in one 1024x1024 image: Houthi strikes on Saudi Red Sea ports,
Trump's Thanksgiving message on Iran, Ukraine's laser drone shootdown,
New Zealand's deadlocked final count, the Thanksgiving storm, and the
million-satellite SpaceX approval.

`main.ts` (Node 22, standard library only) copies the committed
`entry.png` to the grader's output directory. `draw.py` is the local
build script that rendered the image with Pillow.
